# 全新界面原型（手机版 + WinUI 3 电脑端）

两套自包含可交互 HTML，不依赖构建，双击即用。

## 文件

- mobile.html：手机版，392 机型框，底部 5 标签（首页，任务，AI 补位，材料，我的），含登录，任务勾选，三档 AI 切换，底部弹层，Toast 反馈
- desktop.html：WinUI 3 风格电脑端，左侧 NavigationView 八模块，顶部 CommandBar，InfoBar 横幅，ContentDialog 弹框

## 设计语言（与现有界面脱钩）

- 主色鸢尾紫加兰紫渐变，纸面质感卡片，柔光渐变背景
- 手机端圆角 16px，桌面端遵循 Fluent 直角小圆角加云母质感

## 功能覆盖

导入通知，确认要求，团队分工，AI 补位（代做，带做，只审），采纳留痕，预审答辩（模拟非官方），导出打印，过程账本

## 打开方式

直接用浏览器打开对应 HTML，点击导航切换，任务可勾选，AI 可切换模式，卡片点击弹出详情层。
