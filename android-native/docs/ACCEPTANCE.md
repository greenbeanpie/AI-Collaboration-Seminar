## 尚未完成的外部与实机验收

- **真实账号与生产授权**：没有用真实业务账户完成系统浏览器授权、Turnstile、回调、退出撤销、角色切换及线上数据写入全流程。新增后端接口和迁移未部署时，安装包不代表已能生产登录。
- **FCM 配置与凭据**：Firebase 应用配置、服务端发送身份/凭据和部署权限仍需实际配置与核对。服务端私钥不得写入 APK、截图或交付文档；现有实现不证明真实推送已发出。
- **真实即时推送**：未完成在线、后台、杀进程、令牌轮换、退出/换号、重复消息、撤权和缺少 Google 服务的实机投递验收。WorkManager 补查不能承诺即时送达。
- **四小时后台录制**：没有完成真实设备四小时录音/录像、锁屏、暂停/恢复、低电量、来电、存储不足、异常退出恢复和片段上传验收；也未完成人工听看检查。
- **付费 AI 与实时语音**：没有进行真实模型、OCR、付费转录/实时连接和供应商计费验收。语音协议、字幕合并或本地朗读的实现不能替代真实服务连通证据。不得为填补验收记录自动调用模型。
- **资源占用对比**：没有完整同设备、同数据、同场景的最终 Release 对比时，不声称一定更省内存/电量。应用本进程与可归因关联进程都应计入，WebView 渲染进程不能漏算；模拟器空白登录页结果不能代表真实项目工作负载。
- **完整业务体验**：复杂标准编辑、图形依赖、权限控制、AI 采纳、创建澄清、富文档结构编辑等仍有契约表单或体验缺口。不能以 API 操作覆盖数充当专用交互完成率。

## 后续验收步骤

1. **固定版本与环境**：记录合并到 `main` 的提交、构建变体、SDK、设备/系统、签名来源与 APK SHA256。保留旧版和用户未同步内容；不得覆盖旧应用的私有目录。
2. **核心静态与自动化**：运行本地构建、类型/契约校验、单元测试、Lint、相关后端与 Web 回归；在手机和平板环境运行当前完整 instrumentation 套件。报告实际通过/失败/未运行数量，并区分模拟接口与真实网络。
3. **授权及权限**：完成授权取消/过期/重放和 PKCE 错误；验证负责人、普通成员、管理员、被移除成员和换号后的资源边界；离开项目/账户不得继续传输上一个账户的文件或录制。
4. **资料与本机数据**：使用文本型/扫描 PDF、DOCX、XLSX、PPTX、音视频和长文样本核对正文、警告与版本；验证续传、低存储和跨进程恢复；首次离线深入口必须单独测试，冲突不能静默覆盖。
5. **扫描页隔离**：确认 prepare 响应无模型任务；旧后端缺少接口时必须停止。验证来源版本/生命周期变化、撤权、重复登记和异常重试；OCR 必须在用户另行确认后执行并独立记录结果。
6. **UI 与设备行为**：核对手机/平板、深浅主题、字体放大、键盘、无障碍、长列表和长文；重要导航不依赖横向滚动；实测录制、后台、语音、推送与分享目标。
7. **资源测量**：使用启用 R8 的 Release 包，记录 Baseline Profile 是否实际生成并打包；冷启动、PSS、空闲 CPU、滚动帧和 APK 大小各场景至少五次，报告中位数/波动。只有相同条件下有效样本才用于新旧结论，无法读取的指标标记未知。

## 发布与完成判定

本地代码合并、远端推送、测试环境部署、生产迁移、应用商店发布是独立操作。文档和安装包准备不构成推送或部署授权。

当前可交付“独立原生预览客户端及可复现验证材料”。只有功能矩阵的剩余项、生产授权所需前提、真实权限/语音/推送、四小时后台录制和资源对比等验收闭环，才可声明全量迁移完成。无法完成的外部条件应明确记录，不以契约表单、模拟结果或未签名构建代替。
