# 安卓原生迁移矩阵

记录日期：2026-10-19。依据集成工作区中的原生客户端和服务端代码只读核对。

当前交付定位是可构建、可安装和继续验收的**独立原生预览客户端**。业务界面使用 Kotlin、Jetpack Compose 和 Material 3；登录通过系统浏览器完成授权，应用内业务不使用 WebView。复杂操作中的原生 schema 表单提供接口可达性，不能据此宣称全量业务体验或真实账户验收已经完成。

## 基础架构与兼容

| 领域 | 当前实现 | 验收限制 |
|---|---|---|
| 工程 | 独立 `android-native/` 工程；最低 Android 8（API 26）；预览包 `cn.buwei.mobile.nativepreview`，Debug 带 `.debug` 后缀 | 与旧 `cn.buwei.mobile` 并存；不自动读取或迁移旧应用私有草稿/录制目录；真实最低版本设备兼容未验收 |
| 界面 | Compose、Material 3、浅色/深色/跟随系统；手机底部导航和平板侧边导航；详情隐藏技术 ID 和传输元数据 | 不代表全部手机/平板尺寸、字体缩放、键盘遮挡和无障碍检查均通过；部分长列表仍需大数据性能验收 |
| 状态与网络 | ViewModel、StateFlow、Repository；OkHttp、Kotlin Serialization；响应体读取与解析在 IO 调度器执行 | 并非每个复杂页面都已拆成独立 ViewModel；真实弱网、切网与后台恢复仍需验收 |
| 本机数据 | Room 快照与待同步记录、应用私有文件；账户隔离；加密保存会话；DataStore 保存外观设置 | 服务端仍是权限和版本权威；缓存不等于持续授权；旧版未同步数据仍保留在旧应用中 |
| 后台 | WorkManager 同步及通知补查；录制使用原生前台服务 | 系统调度、电池优化和厂商后台策略会影响执行时机；未完成四小时稳定性与耗电验收 |

## 业务能力

“专用界面”表示已编写面向具体业务的 Compose 交互；“契约表单”表示通过既有 API 的类型化原生控件操作。两者都需要进一步真实业务验收。

| 功能 | 当前原生能力 | 尚未闭环的体验或验收 |
|---|---|---|
| 登录与账户 | 系统浏览器授权、一次性授权码和 PKCE 回调；独立会话；账户资料、安全与恢复邮箱入口 | 生产环境授权服务部署、Turnstile/浏览器回调、真实注册/找回/验证流程、真实多账户切换未验收；部分账户操作仍为契约表单 |
| 项目创建 | 专用创建页：模板/恢复草稿、编辑和保存、手动或 AI 任务预览、确认提交；绑定草稿版本与预览身份 | 创建附件及澄清等复杂向导尚未全部变成专用原生交互；AI 预览未进行付费调用验收 |
| 项目与任务 | 项目/任务列表、搜索与分页、详情、项目分区；创建、领取、指派、依赖、提交、审阅及重开等操作可达 | 复杂动作主要使用契约表单；图形依赖编辑、完整成员选择器及真实角色/生命周期组合未全部验收 |
| 私密问询 | 专用任务内一对一问询、收件人成员选择、会话/回复、分页；只标记当前展示消息为已读 | 后端控制可见范围；真实不同成员、权限撤销及跨设备未读一致性未验收 |
| 成果材料 | 原生详情和版本入口；递归编辑文字叶子、添加段落；保留富文档块、marks、attrs、表格、引用、未知节点和附件；乐观锁保存 | 无完整格式工具栏、块移动和表格结构编辑；未知节点保留但不可编辑；保存的 Markdown 由服务端从文档生成；大型文档交互性能未验收 |
| 资料库与来源 | 统一资料、材料、来源、文件/回收站入口；版本、解析、恢复和用途等相关操作；附件下载与原生预览 | 多步骤版本对比与引用定位仍有契约表单/简化呈现；真实来源全生命周期验收未完成 |

## 契约覆盖的解释

当前集成 OpenAPI 包含 311 个操作；生成器与构建中的资产校验是实际数量和一致性的依据。覆盖范围包含认证、原生设备和扫描页准备新增接口，不能沿用早期“304 个”快照作为当前总数。

schema 表单提供嵌套对象、数组、枚举、开关和基本校验；路径/查询参数编码、明确提交及错误保留。二进制接口交给文件流工具，不能以 JSON 表单代替文件。普通账户隐藏管理入口，但高级表单尚未为每个动作完整映射前端权限，后端必须继续校验。

接口契约可达、代码已编写、模拟数据测试通过、真实业务验收通过是不同状态。移除“原生预览”标识之前，应按 [验收限制与验证清单](ACCEPTANCE.md) 闭环专用体验、实机、真实账户和资源测量结果。
