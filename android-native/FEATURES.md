# 原生前端迁移状态

当前源码版本为 `0.2.1-preview`（versionCode `3`）。业务导航已接入专用 Compose 工作区，通用 API 操作表单已从 `FeatureScreen` 移除；原生客户端沿用现有后端接口、账号、项目数据、权限和版本规则。

| 业务入口 | 当前原生交互 |
|---|---|
| 项目首页、概览、活动 | 项目搜索分页、进度与待响应事项、项目概览、活动记录及项目分区导航 |
| 创建项目 | 模板与草稿、草稿专用附件、手动/AI 预览、澄清回答、固定预览确认提交 |
| 任务与团队 | 筛选分页、任务设置与依赖、领取分工、附件与固定版本提交、验收重开、问询、成员权限、邀请审批与加入 |
| DSH 与 AI 协作 | 设备配对和项目绑定、任务交接与成果复核；AI 对话及起草/引导/审阅三模式、历史与人工复核采纳 |
| 资料与成果 | 单一新增入口、资料用途、贡献者、归档和回收恢复、固定版本比较、目录搜索和原文定位、正文/OCR/总结处理 |
| 富文档编辑 | 格式、内容块、列表、表格、撤销重做、本机暂存恢复、人工核对版本冲突；保留引用、未知节点与附件 |
| 标准、评分与演练 | 标准编辑与版本、固定依据评分、人工修正与历史、追问、预审、文字/原生语音排练 |
| 账户与协作支持 | 资料、安全、隐私和恢复邮箱、通知设置与收件箱、工单及附件、People 人员资料、帮助文档 |
| 管理、录制与导出 | 管理专用工作区、原生拍照录音录像及恢复、分片传输、原文件预览与系统分享、成果导出 |

完整能力、限制及代码实现与外部验收的区别见 [迁移矩阵](docs/MIGRATION_MATRIX.md)。当前 311 个生成的 API 契约用于一致性与校验，不表示测试覆盖率或完整业务验收率。

请同时阅读 [架构与构建说明](README.md)、[最新验证报告](VERIFICATION.md) 和 [验收边界](docs/ACCEPTANCE.md)。专用界面的接入不代表真实生产授权、推送、模型、四小时录制或资源占用目标已经通过，也不能据此宣称全目标完成。
