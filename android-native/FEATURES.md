## 高级原生契约表单

- `scripts/generate-contracts.mjs` 从 `backend/openapi/openapi.json` 生成 `GeneratedContracts.kt`，当前 304 个操作。`--check` 检查生成内容与服务端契约一致。
- 支持嵌套对象、数组、枚举、开关、字符串/数字、可选字段与 oneOf/anyOf 选择；校验必填、长度、数值、枚举、UUID 和正则。任意文档对象提供字段/对象/列表控件，未使用原始 JSON 输入框。
- 路径参数与查询参数编码，相关记录携带标识与版本；所有请求均调用现有同源 API。二进制接口明确转交文件流工具，不用文本冒充文件。
- 所有提交先确认；请求不自动重试，同一未变表单的手动重试复用幂等键；失败保留表单。AI 后台轮询仅执行 GET，不触发模型或重放写入。
- 普通账户不显示管理员操作，部分项目操作按负责人/权限控制。服务端仍是权限权威；高级工具尚未为每个操作实现精确的客户端权限映射，可能得到 403，不能宣称角色体验完整。
- 列表、详情和高级操作使用 Compose 控件。结构化结果支持展开、文本选择；长列表目前使用滚动 Column，尚需迁移 LazyColumn 后做大数据性能验收。

## 验证

- 已执行生成脚本与 `node android-native/scripts/generate-contracts.mjs --check`，检查 304 个契约。
- 已执行 `node android-native/scripts/check-feature-routes.mjs`，核对 15 个硬编码操作和契约查找与 OpenAPI 一致；添加 Kotlin 帮助函数测试，覆盖工具次数语义、富文档无损编辑、写入校验及契约身份唯一。
- 未以真实账号调用模型或修改生产数据。
- APK 编译、Android Lint、单元/UI 测试和模拟器/实机结果以根任务最终验证报告为准；本子任务独立目录最初无 Gradle/JDK 脚手架，不能单独宣称已编译。

## 完成标准

以上“仍需”全部闭环，关联文件、录制、离线与认证模块集成，且真实权限、手机/平板、原生后台行为和性能对比通过后，才可移除“预览”并声明全量迁移。高级操作可达性只能作为开发辅助，不替代专用业务界面验收。
