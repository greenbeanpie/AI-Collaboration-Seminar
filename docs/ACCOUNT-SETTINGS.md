# 账户设置

登录后从主导航的“账户设置”进入 `/app/settings`。

- 昵称：1–64 字符，去除首尾空白，拒绝控制字符。仅更新 `users.display_name`；用户 ID、用户名、联系邮箱、邀请规则和项目成员关系保持不变。昵称保存后更新会话缓存并刷新项目查询。
- 密码：验证原密码；新密码沿用注册的 12–128 位策略，禁止与原密码相同，使用既有随机盐 scrypt N=32768/r=8/p=3。确认后提交，取消清空输入；提交锁防止重复请求，失败清空密码并保留页面。
- 成功后原子撤销该用户全部会话（包括当前设备），清理当前账户本地缓存并返回登录页，明确提示使用新密码登录。
- 密码更新以旧哈希作 compare-and-swap；并发改密只允许一个成功。登录创建会话也检查刚验证的哈希，防止旧密码验证与改密交错时创建新会话。
- 设置写接口要求 `X-Account-Settings: 1`，结合全局 Origin 白名单阻止跨站表单请求。密码修改每账户 5 次/15 分钟、每 IP 30 次/小时；昵称每账户 30 次/小时。沿用持久化原子限流，不存明文身份或 IP。
- 无新增迁移、绑定、资源或 Secret；已有密码账户迁移是前置基线。

## 验证

后端新增测试覆盖昵称、原有账户/项目成员、未登录/CSRF、长度和控制字符、错误原密码、同密码、限流、哈希与会话撤销、重新登录、并发改密。前端新增测试覆盖昵称缓存、取消、错误原密码、重复确认、成功退出。

浏览器仅操作独立本地 D1 夹具：昵称更新侧栏；取消清空输入；错误原密码保留登录；重复确认；成功返回登录提示；新密码重新登录；浅色/深色/跟随系统组合与无脚本异常。线上仅做匿名 UI、health、门禁和版本检查，不修改真实账号密码。
