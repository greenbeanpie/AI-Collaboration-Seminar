# 云端界面调整需求与验收记录

记录日期：2026-10-01

## 工作范围

全部开发、检查与结果记录在云端完成，不访问或操作本机。本次实施、验证及发布使用云端，按用户确认将完成的变更推送至现有 main 并部署既有前端 Worker。

项目一：职业工作台。项目二：AI 项目办公室。

## 用户需求

1. 仅项目二参考提供的 Cloudflare 截图布局：应用标题位于左上，左侧导航位于标题下方，顶栏操作位于右侧；优化顶栏各组件的尺寸、间距及对齐
2. 将已有个人资料设为单独的左侧导航入口
3. 将主题按钮恢复到顶栏，同时统一设置页面中的控件样式
4. 个人资料默认展示阅读视图，右上提供编辑按钮；进入编辑模式后，Markdown 编辑区位于左侧，预览位于右侧

## 范围边界

- 第 1 项仅适用于项目二；第 2–4 项适用于两个项目中已有的相应能力
- 项目一现有个人资料为结构化资料，不新增公开 Markdown 后端或未经请求的公开资料能力；以现有资料能力实现默认阅读与显式编辑
- 保留最新通知、手动更新、统一设置、统一 AI 配置、个人资料隐私及 AI 使用同意控制
- 不更改 workers.dev、生产路由、线上账户、密钥或部署配置

## 验收标准

- 项目二桌面布局呈现左上应用标题、下方独立左导航、右侧顶栏操作；窄屏可正常导航且无横向溢出
- 个人资料可由独立导航直接进入，刷新及前进/后退保持正确页面
- 顶栏可切换主题，设置中的主题控件行为一致，保留主题持久化与系统主题选项
- 个人资料进入时为阅读状态；编辑、取消、保存、错误及重复进入流程正确，不丢失已保存资料
- 项目二 Markdown 编辑与预览在桌面左右排列，窄屏合理堆叠；隐私与 AI 同意设置保留且无默认放宽
- 受影响功能测试、类型检查、静态检查及构建通过；记录云端视觉检查及其限制

## 结果

- 已实现项目二左上品牌、品牌下左导航及右侧顶栏操作
- 已为两项目添加独立个人资料入口，并保留旧设置链接的兼容跳转
- 已恢复顶栏主题控件，并统一设置中的主题及输入控件样式
- 项目二默认显示个人主页阅读视图；显式编辑时左侧 Markdown/资料、右侧实时内容和公开展示预览；窄屏改为上下排列
- 项目一保留既有昵称/用户名账户资料，默认阅读及显式编辑；不新增 Markdown 后端或公开资料功能
- 隐私、搜索可见性、AI 同意控制及未保存编辑保护保留
- 已有更新、通知及 AI 热修随本次基线保留
- 功能测试、类型检查、静态检查和生产构建结果以发布记录为准
- 实际云浏览器视觉检查受环境限制，不能把代码/DOM 回归视为截图视觉验收通过
- 未创建或修改线上账户、密钥或权限；未访问本机
