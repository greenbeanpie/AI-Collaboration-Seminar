# 新建项目：分步创建与模板预览

新建入口提供分步创建和从模板创建两种方式。目前模板目录只有「空项目」，不预设任务、资料或评分内容。

选择空项目后进入私有草稿工作区。页面沿用正式项目的概览、任务、资料、评分和团队结构，但尚未建立正式项目：团队成员不会收到邀请，任务不会进入协作列表，也不会发起评分或 AI 作业。

用户可以编辑项目基本信息、主目标、依赖子任务、背景及成果文档、评分标准和邀请配置。保存草稿用于暂存和刷新恢复；最后「保存并创建项目」将所确认内容一次性保存为正式项目，然后进入项目空间。

## 数据与兼容

- 复用现有创建草稿、账户权限、revision 版本校验及提交结果恢复机制。
- 模板数据存入创建草稿的 JSON 配置，旧分步草稿无需迁移或重建。
- 空模板不调用 AI；模板预览使用草稿接口，不向尚不存在的项目接口写入。
- 最终保存以草稿 ID 保证只创建一个项目；版本冲突时保留本地编辑，要求用户核对后重试。
- 私有草稿只对本人可见；正式项目和邀请只在最终提交成功后生效。
