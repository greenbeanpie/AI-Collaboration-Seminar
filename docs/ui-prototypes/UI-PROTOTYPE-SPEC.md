# 「补位 · AI 项目办公室」全新双端界面原型设计规范（WinUI 3 桌面端 + 移动原生端）

> 这是设计参考，不是客户端功能完成清单。当前 Windows 实现与验收边界见 [外观实现说明](../../windows-native/docs/APPEARANCE.md)，Android 实现见 [功能矩阵](../../android-native/FEATURES.md)。

> **设计原则说明**：本方案完全基于「补位 · AI 项目办公室」的核心业务功能与安全契约从零正向设计，不沿用既有网页或旧版客户端界面布局。电脑端深度契合 **Windows 11 Fluent 2 / WinUI 3 (Windows App SDK 2.5.1)** 原生材质与控件规范；手机端采用 **单手拇指热区 + 移动现场采集与随身语音演练优先** 的卡片流架构。

## 三、 电脑客户端（WinUI 3）架构与原生控件映射

针对桌面大屏与重度文档/任务处理场景，电脑端摒弃了传统的「单栏页面跳转 + 多重模态弹窗嵌套」，采用 **WinUI 3 三栏主从协同架构（Left NavigationView + Center Workspace Frame + Right Contextual Inspector）**：

### 1. 窗口壳层（Shell）四层结构
1. **沉浸式自定义标题栏 (`Window.ExtendsContentIntoTitleBar = true`)**
   - 左侧：应用徽标 + 项目快速切换器 + 当前工作区面包屑（BreadcrumbBar）。
   - 中间：全局命令与智能检索框（`AutoSuggestBox`，快捷键 `Ctrl + K`），支持跨任务、固定版本文档、评分标准上标引用检索。
   - 右侧：本机 SQLite 离线快照同步胶囊（显示当前 `revision`）、本机 **DSH Agent Bridge** 在线状态灯，以及原生窗口最小化/最大化/关闭按钮。
2. **左侧导航栏 (`NavigationView` · `PaneDisplayMode="Left"`)**
   - 顶部固定「当前活跃项目卡片」（展示项目角色、距离截止剩余时间）。
   - 核心业务六大入口：**项目概览**、**任务协作与验收**、**资料库与富文档**、**标准/评分与语音演练**、**AI 协助与 DSH 桥接**、**团队权限与导出**，通过语义化 `InfoBadge` 实时透出待审数量与未读私密质询。
   - 底部固定全局入口：**全局个人资料与 AI 授权**、**站内支持工单 & 帮助文档**、当前登录账户卡片（切换账户时立即取消旧请求并清空内存状态）。
3. **中间主工作区 (`Frame` + `CommandBar` + 虚拟化 `ItemsRepeater`)**
   - 承载高密度的平级依赖任务列表、分步/模板创建向导、块级富文档编辑器（`RichDocumentEditor`）与逐维度评分条。
4. **右侧常驻上下文智能检查器 (`SplitView` / `AcrylicBrush` Inspector)**
   - **告别弹窗遮挡**：点击任意任务或文档时，右侧检查器平滑切换展示该对象的「固定版本 SHA-256 证据链」、「任务内一对一私密质询会话」、「语音答辩实时字幕核对小窗」以及「AI 异步作业断点续跑监控」。
5. **底部原生状态栏 (StatusBar)**
   - 实时展示 `/api/v1` 同源连接状态、`SaveBeforeCloseAsync` 本机草稿持久化锁（明确提示密码/API Key 绝不落盘）以及原生内存占用。

### 2. 六大核心业务模块在 WinUI 3 下的交互设计

| 业务模块 | 核心功能点覆盖 | WinUI 3 原生控件选型 | 关键交互与防错机制 |
| :--- | :--- | :--- | :--- |
| **1. 办公总控台 & 创建向导** | 独立主目标（不计入子任务工时）、分步/AI 预览创建、四项协作规则配置 | `Expander`、`ProgressBar`、`TeachingTip`、`GridView` | 顶部高亮「独立主目标」横幅；AI 创建预览支持核对目标、引用原句与页码后再二次确认提交。 |
| **2. 任务协作与三级验收闭环** | 平级依赖任务、软依赖提示（允许提前认领/提交）、自动初审（待人工审核附件）、任务内一对一私密质询 | `ItemsRepeater`（虚拟化列表）、`Segmented`、`InfoBar`、`SplitButton` | 前置依赖未完成仅显示琥珀色软提示，不锁死「我来认领」；包含现场实物操作的任务自动禁用 AI 代实施并展示原因；私密质询严格限制仅发起人与质询对象可见。 |
| **3. 资料库、Office 提取与富文档** | 按任务顺序分类文件+公共文件、本机 DOCX/XLSX/PPTX 有界提取、块级富文档编辑、归档与回收站 | `TreeView`、自定义 `RichDocumentEditor`、`CommandBar` | `OfficeTextReader` 按 16,000 字符安全分批与 SHA-256 校验导入，不静默触发付费 OCR；保存草稿严格携带 `expectedRevision`，冲突时保留双端内容对照。 |
| **4. 唯一生效标准、检查与语音演练** | 纯评分维度+权重+编号参考文件上标、固定版本材料检查、本地中文 TTS 朗读提问 + 16kHz PCM 实时转录核对 | `RatingControl` / 自定义原生分数条、`MediaCapture`、`SpeechSynthesizer` | 标准阅读区顶部展示项目级/任务级区分提示；语音演练提供实时音频波形与**可编辑字幕核对框**，允许人工修正专业术语后再提交评分，失败可一键回退文字。 |
| **5. AI 三模式协助 & 本地 DSH 桥接** | 代做(`do`) / 带做(`guide`) / 只审(`review_only`)、从停止处继续、HTTPS 持久配对 DSH、未知派发状态锁 | `ContentDialog`、`CheckBox`（复核勾选）、`ProgressRing` | 采纳 AI 或 DSH 草稿前强制勾选「已人工复核」并二次核对目标 `expectedRevision`；网络异常导致派发结果不明时启用持久锁阻止重复计费重放。 |
| **6. 团队细粒度权限、双轨资料与导出** | 5 项独立项目授权、网站三级管理员与项目身份隔离、个人资料「公开」与「AI 推荐授权」分离、JSON/MD/PDF 导出 | `DataGrid` / `ItemsRepeater`、`ToggleSwitch`、`FileSavePicker` | 明确区分「向其他用户公开展示」与「发送给 AI 进行任务偏好推荐」两个独立开关；每周可用时间锁定为「仅本人可见、绝不发给 AI」。 |

## 四、 手机客户端（Mobile Native）架构与场景化重塑

手机端不照搬桌面端的三栏宽表，而是围绕**移动高频场景（随时审批、现场录音/拍照采集、通勤随身语音演练、即时回复私密质询）**设计单手友好的 5 栏底部导航架构：

1. **底部五栏导航（Thumb-Zone TabBar）**
   - **总览 (Home)**：顶部渐变主目标进度卡 + 「待你优先响应」紧急队列（待人工终审任务、未读私密质询一键直达）。
   - **任务 (Tasks)**：顶部分段筛选（待办/我的/私密质询），任务卡片内嵌「接受 / 需改进 / 需重做」大尺寸拇指按钮与内联私密质询快捷回复栏。
   - **采集/资料 (Capture & Materials)**：置顶**「5 分钟自动分段落盘录音器」**（展示实时动态声波、暂停保留状态、分段恢复日志提示，必须经用户显式确认才上传）与**「扫描件拍照补页」**入口（自动携带原文件派生归属）。
   - **演练/评分 (Voice & Rubric)**：随身语音答辩模式——上方展示评委问题（系统本地中文 TTS 语音播报），下方提供大字号**实时转录字幕核对与手动改词区**，底部配「按住补充语音 / 点击确认提交」通栏按钮。
   - **我的/同步 (Me & Sync)**：集中处理**离线编辑版本冲突对照**（地铁/弱网离线修改与服务端新版本冲突时，严禁静默覆盖，提供左右对照与合并保存）以及全局个人资料双轨隐私开关。
