# 多份成果引用恢复

## 已确认原因

截图评分 107b3f3c-131b-421d-975e-20096872fdef 的自动修正请求中，`decisionReferences[3]` 同时包含有效的数据汇总、分析报告和一个空正文旧版本。旧校验把整组 ID 写入 `invalidIds`，错误地指示模型排除两个有效成果。线上 R2 输入快照确认这三个 ID 确实同时被标错；D1 固定版本正文长度分别为 1341、1600 和 0 字符。修正后的报告因此错误地声称只有方案可以引用。

## 修改

- 混合引用仅反馈真正未读取的 ID；结构错误单独说明，不把有效 ID 标为无效。
- 两条共享输出修正链路均传递有效引用、材料版本对应关系及缺失的已读正文。已经在原始输入中的正文不重复传递；完整上下文超限时继续按原有保护停止，不截断证据。
- 更新修正提示词版本，使旧的错误修正输出不会被当作新修正结果复用；原调查检查点与付费调用保留。
- 保持引用与逐字证据的发布校验，不接受空正文或伪造引用。
