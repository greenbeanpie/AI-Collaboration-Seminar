# 任务完成统计卡进度条

日期：2026-10-03。实现基于 `5682bf6322641bbe0b39b382fca96863e03a543b`，保留该基线的首页邀请入口、待响应事项与 AI 补充询问功能。

## 范围与口径

- 已查看用户提供的两张截图：项目概览「任务完成 0/20」卡和首页「任务完成率 8% / 2 / 25 项任务已完成」卡。
- 这两张卡共用 `TaskCompletionMetric`；增加纯色进度条，卡片底色及边框与进度颜色一致，分别定义浅色、深色主题。
- 低于 50% 为红色，50% 到未完成为黄色，全部完成才为绿色。进度条没有渐变。
- 分子仍为服务端 `status === 'done'` 的任务数；分母是该统计范围内全部任务数。首页按现有口径排除归档项目，并保留项目内任务去重。不以「可完成任务」数量代替全部任务。
- 进度条长度采用实际比例，百分比显示为整数；未全部完成时最高显示 99%，避免四舍五入造成假 100%。计数规范化并限制在有效范围内。
- 零任务显示 0%，不视为完成。数据加载或读取失败时显示未知状态，不展示已有缓存统计、进度条或完成色。
- 保留文字计数和百分比，增加进度条无障碍名称、范围、当前值及文字说明；强制颜色模式保留边框和可辨识进度。
