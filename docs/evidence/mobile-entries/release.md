# 文档中性表述与手机功能入口检查

2026-10-03。已发布到既有网站前端。技术文档标题和说明改为中性的系统实现描述，保留详细数据字典、AI执行链路、SQL和维护验证内容；未将具体读者身份作为前提。

## 检查范围

仅检查当前菜单、路由和内部页面/弹窗入口能否找到、完整显示、点击或展开；不验证业务结果，不执行保存、提交、上传、删除、邀请、认领、评分、模型生成、设备安装、通知授权或退出登录。

真实Edge浏览器使用320、375、390像素视口和本地合成GET响应，覆盖一般用户、管理员、超级管理员及项目负责人/普通成员边界。所有非GET API请求被脚本阻断；实际记录为零写请求。

- 全局：7个菜单、首页新建/项目卡/待办、归档弹窗、头像、账户操作、通知面板、用户搜索和工单详情。
- 项目：5组导航及概览/团队分区、团队设置、导出、全部旧地址兼容入口。
- 任务：新建表单、AI规划弹窗及建议历史、任务详情、设置/提交页签及提交历史。
- 资料：3个工作区入口、3种来源导入表单、来源全文、文档/版本/讨论、附件回收站、AI面板与会话历史、导出菜单。
- 评分：3种形式、新建/修订标准、评分记录、人工评分/修正表单和历史演练。
- 创建：方式选择、模板目录、已有草稿、向导5个步骤和模板5分区；空模板创建按钮仅检查可见，其创建动作不执行。
- 账户：按角色检查5/7/8个设置分类、资料编辑及导入候选、成员权限表单；登录、注册及游客页面入口。

新建项目侧栏快捷入口在手机隐藏，但首页有对应可用入口；项目桌面链接在手机隐藏，但有选择器替代。这些有替代入口的设计及合法权限隐藏未视为故障。

## 发现与修复

文档编辑区在手机按钮换行后，导出菜单仍右对齐到左侧按钮，导致菜单越出左边界，Markdown/打印选项被裁切。基线截图和失败结果在 `baseline/`。

通用DropdownMenu在展开前按视口及裁切祖先的实际边界定位菜单，限制宽度并允许长选项换行；窗口变化重新计算位置。保留原有焦点、Escape、外部点击和执行后关闭行为。320/375/390下，导出菜单完整可见，选项中心实际命中按钮；“更多”及历史入口同样通过。

未发现其他需要修复的入口问题。初轮检查的标签和旧记录响应不匹配属于检查脚本/夹具问题，已按实际文案与响应结构纠正；没有为这些情况修改业务代码。
