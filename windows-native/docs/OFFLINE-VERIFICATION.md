本记录对应后续 0.1.1 源码；没有用新源码替换或复用 0.1.0 的安装包、性能或原生窗口证据。未执行生产请求、GUI 自动化、付费识别或模型调用。

## 文本准备范围

- 保留项目、权限、目标、任务/文件/提交/评论、资料库和来源元信息的准备；补齐来源当前固定版本及成果列表返回的全部历史版本。
- 递归读取固定版本目录、每个原文分节及 `neighbors=true` 的全部续读页，查询形状与原生阅读界面一致，支持这些入口未曾在线打开就第一次离线读取。
- 默认累计处理最多 128 MiB 序列化 UTF-8 文本、2,000 次接口读取、每条列表/目录/分节分页链 200 页；超限或分页不前进立即停止并保留已有缓存，不记为就绪。界面按实际接口尝试次数（含失败尝试）和已保存入口数报告进度。
- 固定版本、类型、生命周期必须一致。错误版本响应不会覆盖已有合法缓存；已知不可访问的固定目录会连同其分节快照失效，保留用户草稿及其他版本。
- 索引构建中、原文覆盖不完整、单一资料禁用/不可访问均明确记为 `partial`。项目成员撤权则清除项目缓存并阻止原有队列继续提交。取消和异常不能留下本次完整就绪状态；中断的 `preparing` 标记表示尚未确认完成，不自动继续准备。
- 文本计量、快照序列化和本机变更叠加在后台执行；读取最终返回前再次核对账户代际。原文件另行下载，准备过程不发起 OCR、分析或模型请求。
