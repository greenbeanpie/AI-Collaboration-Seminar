# 任务成果离线提交补齐

对应 0.1.1 后续源码，不回填 0.1.0 安装包、性能或 GUI 验收结论。全部验证使用本机合成 HTTP、SQLite 和 DPAPI；未执行生产写入、真实账号或模型调用。

## 原生操作及持久化边界

- 联网提交强制读取完整文件分页，不回退缓存。排除已归档、删除的文件，固定有效版本；缺版本、重复标识/分页、不属于当前任务及超过十个有效文件均拒绝提交。
- 独立离线入口仅读取当前账户缓存。任务负责人、状态、草稿 revision、每一页及固定文件版本必须完整；预览展示最早缓存时间、任务版本、正文和全部固定文件版本。原文件二进制无需重新上传；缓存可能落后于服务端。
- 确认后先保存正文、任务版本、文件版本及稳定幂等键到 SQLite，状态为 `awaiting_confirmation`。不在此入口发起 HTTP，不由后台发送。已有相同任务的待确认、待同步或冲突提交时拒绝创建第二条意图。
- 同步中心提供联网分页读取提交历史、导出完整本机修改及人工确认发送。确认后仍由现有 `/offline-sync` 服务端权限、版本与幂等协议处理；启用自动评价的项目可能产生费用，界面明确提示。
- 发送前持久标记 `sending`。进程中断保留该状态；网络中断、取消、响应损坏、408/429/5xx 或幂等处理中均转为或维持需要人工核对的状态。后台不静默重试；成功响应还需匹配提交标识、任务、账户、正文及文件版本后才移除本机记录。人工恢复沿用原键和原正文，不生成新键。真实版本冲突保留本机数据；重编辑须先核对当前任务。
- 发送与队列删除共用同步锁，避免发送尚未结束就删除原意图。移除队列记录不代表撤回服务端提交，本机草稿仍保留。账户变化、已知撤权或取消不得跨账户入队。

## 未验收与限制

- 本机队列保持 FIFO。待人工确认或异常的首条记录会暂停后续记录；需先发送、核对或移除该条后再继续。
- 不能保证多个服务端分页处于同一事务快照；发现重复即拒绝，最终由提交接口权限和 revision 检查裁决。离线缓存明确可能过期，不声称掌握服务端最新文件版本。
- 本次没有任务文件专用上传/替换、AI 建议、辅助计划或手动 Agent 上下文导出；这些仍为迁移缺口。
- 未操作原生 GUI、真实角色、中文输入/缩放、实际断网设备、真实自动评价、长时间恢复或低磁盘验收。0.1.0 原始性能数据仅属于旧冻结包，不能当作 0.1.1 的测量结果。
